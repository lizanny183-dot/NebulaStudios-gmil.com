# Nebula Studios · Echoes (sitio web)

Cómo abrirlo: doble clic en `index.html`, o en Visual Studio Code instala "Live Server" → clic derecho en `index.html` → *Open with Live Server*.

## Estructura
- `index.html` — contenido y secciones (en orden).
- `css/styles.css` — estilos y animaciones. `css/logo-mask.css` — logo de Nebula (generado, no lo edites).
- `js/main.js` — navegación por secciones, música, galería, storyboard, ampliar imágenes.
- `assets/images/` — imágenes. `assets/audio/theme.mp3` — **pon aquí tu canción** (MP3). `assets/video/trailer.mp4` — tráiler de Echoes (ya incluido).

## Cosas fáciles de cambiar
- Textos: en `index.html`. Nombres de personajes: buscar "Shawn" e "Ivon".
- Escenarios de la galería: lista `G` en `js/main.js`.
- Colores: variables al inicio de `css/styles.css`.
